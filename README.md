# smart-canteen-using-C
# 🛒 Smart Canteen Token & Billing Management System

A console-based **Smart Canteen Token & Billing Management System** developed in **C**. This project streamlines the traditional canteen ordering process by digitizing menu browsing, order placement, automated billing calculations, and a sequential token generation system to minimize queues and manual errors.

---

## 🚀 Key Features & Highlights

- **Interactive Menu Display:** Browse available food and beverage items with corresponding prices.
- **Order Placement & Customization:** Select multiple items, specify quantities, and modify orders seamlessly.
- **Automated Billing Engine:** Instantly calculates sub-totals and final payable amounts.
- **🎫 Dynamic Token Generation Concept:** 
  - Automatically assigns a unique, sequential transaction or order token upon successful payment/checkout.
  - Acts as a digital queue identifier so customers can track their orders without paper slips.
- **User-Friendly CLI:** Clean, intuitive, and menu-driven command-line interface.

---

## 🛠️ Tech Stack & Concepts

- **Language:** C (Standard C99 / C11)
- **Core Concepts:**
  - Control structures (Loops, Switch-cases)
  - Modular Programming (Functions)
  - Structures (`struct`) for managing menu items, carts, and customer order records
  - State tracking for sequential token numbering
